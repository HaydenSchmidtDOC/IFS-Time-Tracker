IFS Time Tracker

A small Windows desktop app for logging hours against IFS project codes and ASNs.

Download

Download the latest version

Download the IFS Time Tracker.exe asset, put it anywhere, and run it — nothing else needs installing. A data/ folder is created next to it on first run.

Updating

Once installed, the app checks GitHub Releases automatically (at most once a day) and offers to update in place when a newer version exists — no need to download a zip and replace the exe by hand. You can also check manually from Settings → Updates → "Check now", or turn automatic checks off there.
