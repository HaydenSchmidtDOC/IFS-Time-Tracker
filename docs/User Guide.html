IFS Time Tracker

A small Windows desktop app for logging hours against IFS project codes and ASNs.

Download the latest version

Download the IFS-Time-Tracker.exe asset, put it anywhere, and run it — nothing else needs installing. A data/ folder is created next to it on first run.

Updating from an older version

If you're on a version before 0.6.0, update once by hand:

  1. Quit the app (right-click the tray icon → Quit).
  2. Download IFS-Time-Tracker.exe from the link above.
  3. Replace your existing IFS Time Tracker.exe with the new file (keep it in the same folder so your data/ folder stays put).
  4. Run the new exe.

From 0.6.0 onward, the app checks GitHub Releases automatically (at most once a day) and offers to update in place when a newer version exists — no more manual downloads. You can also check manually from Settings → Updates → "Check now", or turn automatic checks off there.
